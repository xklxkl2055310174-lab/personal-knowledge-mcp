# 上下文管理策略

上下文预算（token budget）决定了一次调用最多能注入多少检索结果，超出预算必须截断或摘要。

full 策略：把所有检索结果完整注入。实现最简单，但在结果较多时 token 成本最高，也容易超出预算被截断。

relevant 策略：按与问题的相关度对片段排序，优先注入最相关的片段，直到用满预算。通常在准确率与 token 成本之间平衡最好。

summary 策略：把长结果压缩成要点列表回填，每条限制长度。适合超长工具输出，例如日志、diff、CI 结果。

token 估算：ASCII 字符约 4 个算 1 个 token，中文字符约 1 个字算 1 个 token；生产环境应换成模型自带的 tokenizer。

每次运行都记录策略、输入 token、输出 token 和是否成功，用数据比较不同策略的成本与成功率。
